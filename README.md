## 中文

最后更新：2026-10-09

暂存盒是一个"稍后再看"的收件箱浏览器扩展。**我们不收集、不传输、不分享你的任何数据。**

### 我们处理哪些数据，以及为什么

| 数据 | 用途 | 存在哪里 |
|---|---|---|
| 你暂存页面的**标题与网址** | 让你在盒子里看到并重新打开它 | 只存在你自己的浏览器本地存储 |
| 你写的**备注**（可选） | 记下"为什么存它" | 同上 |
| 视频的**播放位置** | 下次从上次的位置继续看 | 同上 |
| 页面的**代表性图片（缩略图）** | 让列表更好认 | 同上 |
| 你**选中并暂存的一段文字**（可选） | 作为该条目的备注 | 同上 |
| 暂存时间、看完 / 删除状态 | 排序与整理 | 同上 |

这些数据**全部产生于你主动按下暂存键的那一刻**（快捷键、工具栏图标或右键菜单）。
扩展不会在后台读取你的浏览历史，也不会读取你没有主动暂存的页面。

### 我们不做的事

- **没有任何网络请求**：扩展不包含 `fetch`、`XMLHttpRequest`、WebSocket，也没有分析、统计、广告或追踪代码。
- 没有账号、没有服务器、没有云端。
- 我们无法看到你的数据，也无法把它交给任何第三方。
- 不出售、不转移用户数据；不将数据用于与本扩展单一用途无关的目的；不用于确定信用度或放贷。

### macOS 上的可选本机组件

macOS 用户可以额外安装一个很小的本机组件，让 Safari 与 Chrome / Edge 读写**同一份本地文件**。
该文件只存在你自己的电脑上，同样不会上传。不安装该组件时，扩展的一切功能都正常，
只是不同浏览器各自保存自己的清单。

### 你的控制权

- **导出**：随时把全部数据导出为一个 JSON 文件。
- **删除**：删除单条（先进回收站，30 天内可撤销），或彻底删除。
- **卸载**：卸载扩展会移除浏览器本地的全部数据。由上述可选本机组件保存的本地文件需要你自行删除。

### 儿童隐私

本扩展不面向儿童，也不会有意收集儿童的任何信息。

### 政策变更

若本政策有变更，我们会更新本页顶部的日期，并在扩展的更新说明中说明。

### 联系我们

如有隐私相关问题，请在 GitHub Issues 提问：
<https://github.com/cfyofjackie/zancunhe-privacy/issues>

## English

Last updated: 2026-10-09

ZanCunHe is a "read later" inbox browser extension. **We do not collect, transmit, or share any of your data.**

### What we handle, and why

| Data | Purpose | Where it lives |
|---|---|---|
| **Title and URL** of pages you save | So you can see and reopen them in your inbox | Your browser's local storage only |
| **Your note** (optional) | To remember *why* you saved it | Same |
| **Video playback position** | To resume where you left off | Same |
| A page's **representative image** | So entries are easy to recognize | Same |
| **Text you selected and saved** (optional) | Used as that item's note | Same |
| Saved time, done/deleted state | Sorting and tidying | Same |

All of this is created **only at the moment you explicitly save something**
(keyboard shortcut, toolbar icon, or context menu). The extension does not read your
browsing history in the background, and cannot read pages you did not choose to save.

### What we do not do

- **No network requests at all**: there is no `fetch`, `XMLHttpRequest`, or WebSocket in the
  extension, and no analytics, telemetry, advertising, or tracking code.
- No accounts, no servers, no cloud.
- We cannot see your data, and we cannot hand it to anyone.
- We never sell or transfer user data; we never use it for purposes unrelated to the
  extension's single purpose; we never use it to determine creditworthiness or for lending.

### Optional macOS helper

On macOS you may install a tiny optional helper that lets Safari and Chrome / Edge read and
write **the same local file**, so two browsers share one inbox. That file lives only on your
own computer and is never uploaded. Without the helper, everything still works — the browsers
just keep separate lists.

### Your controls

- **Export**: export all data to a JSON file at any time.
- **Delete**: delete individual items (they go to a 30-day trash and are undoable), or delete forever.
- **Uninstall**: uninstalling removes all data stored by the browser. A local file written by the
  optional helper must be deleted by you.

### Children's privacy

This extension is not directed at children and does not knowingly collect information from children.

### Changes

If this policy changes, we will update the date at the top of this page and describe the change
in the extension's release notes.

### Contact

For privacy questions, please open a GitHub issue:
<https://github.com/cfyofjackie/zancunhe-privacy/issues>
